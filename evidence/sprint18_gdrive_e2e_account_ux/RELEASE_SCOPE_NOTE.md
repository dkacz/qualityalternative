# Sprint 18 Release Scope Note

Sprint 18 is prepared as a GitHub debug APK alpha release for the current Quality Alternative test channel, not a Play Store broad-public listing.

The Google OAuth app is published and the emulator/tester flow completes with the non-sensitive `drive.file` scope. Google still displays missing Privacy Policy / Terms links during OAuth consent. That warning is documented as a product/compliance follow-up before broad public distribution. It is not treated as a Sprint 18 blocker because the release target is a debug APK alpha and the live evidence proves authorization, Drive write, and Drive readback for the current app build.
